# Demonstration cards for human review

Draft hooks are short storytelling prompts, not recorded 15-second videos.
Use natural invocation text in the current host; slash syntax is not claimed
universal. Scenario receipts are linked from the [gallery](demo-gallery.md)
and [28-row ledger](upgrade-ledger.md). No card establishes comparative lift.
